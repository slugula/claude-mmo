- Top-left context info shows: `[Primary Verb] [Subject Name]` (verb = white, subject = orange)

  - "Walk here" is treated as a single verb (no orange "here")

  - "Attack Chicken" = verb "Attack" (white) + subject "Chicken" (orange)

- Right-click opens OSRS-style context menu

- Context menu order: Primary Action → Other Actions → Walk here → Cancel

- Left-clicking anywhere closes an open context menu

- Cursor becomes a pointer when hovering interactable objects

- Available actions are tied to the entity itself.

- All entities have a "Walk here", "Examine" and "Cancel" action, irregardless of entity type.

- When entities have unique actions in their spec, the first action in the list is considered the primary one, while the rest are secondary.
